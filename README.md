# E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview
This project demonstrates an end-to-end Power BI solution for analyzing e-commerce sales data. The dashboard provides insights into sales performance, profitability, customer behavior, and product trends through interactive visualizations.

---

## 🎯 Objectives
- Track overall sales and profit performance
- Analyze monthly and yearly sales trends
- Identify top-performing product categories
- Understand customer purchasing behavior
- Enable data-driven decision making

---

## 🗂 Dataset Information
The dataset includes:
- Orders data (Order ID, Date, Quantity, Sales, Profit)
- Product categories and sub-categories
- Customer segments and regions
- Payment modes

---

## 🛠 Data Cleaning & Transformation
Performed using Power Query:
- Removed duplicate records
- Handled missing and inconsistent values
- Standardized column formats
- Created relationships between tables

---

## 📊 Key Metrics (DAX Measures)
- Total Sales
- Total Profit
- Quantity Sold
- Average Order Value
- Sales Trend (Month / Year)

---

## 📈 Dashboard Features
- KPI Cards for quick insights
- Sales & Profit trend analysis
- Category-wise performance breakdown
- Region-wise sales analysis
- Interactive slicers for filtering

---

## 🔍 Key Insights
- High-performing product categories drive majority of revenue
- Sales fluctuate seasonally
- Certain regions show higher profitability
- Online payments are the most preferred payment method

---

## 🧰 Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

---

## 📌 Conclusion
This project showcases real-world business intelligence reporting using Power BI and highlights strong skills in data cleaning, DAX, and dashboard storytelling.
